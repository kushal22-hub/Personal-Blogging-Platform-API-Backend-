# 📝 Personal Blogging Platform API

A RESTful Blogging Platform API built using **Node.js, Express.js, MongoDB, and Mongoose**. It provides endpoints for user authentication, blog post management, and comment management.

## 🚀 Features

- User registration and login
- JWT-based authentication
- Access and refresh token management
- Secure password hashing
- Create, read, update, and delete blog posts
- Manage comments (CRUD operations)
- Protected routes and authorization
- MongoDB database integration
- Cookie-based refresh token handling

## 🛠️ Tech Stack

- **Runtime:** Node.js
- **Backend:** Express.js
- **Database:** MongoDB
- **ODM:** Mongoose
- **Authentication:** JWT
- **Password Security:** bcrypt
- **API Testing:** Postman

## ⚙️ Installation

1. Clone the repository:

   ```bash
   git clone <your-repository-url>
   ```

2. Navigate to the project directory:

   ```bash
   cd blogging-api
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Create a `.env` file and configure your environment variables.

5. Start the development server:

   ```bash
   npm run dev
   ```

## 📌 API Base URL

```text
/api/v1
```
